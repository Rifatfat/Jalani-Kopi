# JALANI KOPI - Design System

## Visual Direction

Style:

* cinematic
* modern
* trendy
* editorial
* immersive
* aesthetic
* visually rich

The website must feel premium and energetic.

---

# Visual Mood

Main feeling:

* Instagrammable
* artistic
* modern
* youthful
* stylish

The design should feel like a fashion campaign mixed with a modern coffee brand.

---

# Color Palette

Primary Background:

* Dark charcoal
* Deep black
* Warm dark gray

Accent Colors:

* Coffee brown
* Warm beige
* Soft cream
* Warm orange glow

Avoid:

* bright blue
* neon green
* random colorful gradients

---

# Typography

Typography style:

* bold
* modern
* clean
* oversized headlines

Use:

* large titles
* editorial layout
* cinematic spacing

Avoid:

* playful fonts
* handwritten fonts
* complicated typography

---

# Layout Style

Use:

* overlapping elements
* asymmetrical layout
* layered visuals
* cinematic spacing
* large typography
* immersive sections

Avoid:

* boring grid layouts
* excessive cards
* generic SaaS sections

---

# Animation Style

Animation style:

* smooth
* immersive
* premium
* cinematic

Use:

* fade reveals
* parallax movement
* floating elements
* stagger animations
* smooth scrolling
* hover transitions

Avoid:

* excessive bouncing
* aggressive motion
* chaotic movement
* flashy animations

---

# Motion Philosophy

Animations should feel:

* intentional
* elegant
* smooth
* emotional

Do not animate everything.

Motion should support storytelling.

---

# Hero Section Style

Hero section should include:

* huge typography
* cinematic entrance
* layered coffee visuals
* animated text
* subtle particles
* immersive atmosphere

The hero section must immediately impress users.

---

# Gallery Style

Gallery should feel:

* editorial
* artistic
* immersive

Use:

* layered image positioning
* mixed sizing
* overlapping compositions

Avoid:

* simple gallery grids

---

# CTA Style

CTA buttons should feel:

* premium
* modern
* bold
* interactive

Buttons must include:

* hover effects
* smooth transitions
* modern rounded styling

---

# Mobile Design Rules

Mobile experience is extremely important.

Requirements:

* responsive typography
* smooth scrolling
* touch-friendly spacing
* optimized animations
* stable layout

Mobile experience must feel premium.

---

# Visual Quality Standard

The website should feel comparable to:

* modern fashion landing pages
* premium product campaigns
* cinematic Awwwards-style websites

Avoid generic template appearance at all costs.
