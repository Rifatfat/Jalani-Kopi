# JALANI KOPI - Product Requirements Document

## Project Overview

JALANI KOPI is a cinematic single-page coffee brand website focused on marketing, storytelling, and WhatsApp conversion.

This is not a dashboard application or fullstack ordering platform.

The website must feel:

* modern
* cinematic
* aesthetic
* immersive
* Gen Z friendly
* visually rich
* premium
* Instagrammable

Main purpose:

* increase brand perception
* attract customers
* encourage WhatsApp orders
* promote franchise opportunities

The website should feel like a modern coffee campaign landing page.

---

# Core Goals

## Primary Goal

Encourage users to order through WhatsApp.

## Secondary Goal

Promote franchise opportunities.

## Visual Goal

Make users feel:

* "This brand looks aesthetic"
* "This coffee shop feels modern"
* "This looks premium and trendy"
