# CODEX MASTER PROMPT

Build a cinematic single-page website for JALANI KOPI using:

* Next.js 15
* TypeScript
* TailwindCSS
* Framer Motion
* shadcn/ui

The website must feel:

* cinematic
* immersive
* aesthetic
* modern
* visually rich
* premium
* editorial
* Instagrammable

This is NOT a dashboard or ecommerce platform.

The website is a marketing-focused coffee campaign landing page.

---

# Important Development Instructions

Focus heavily on:

* visual hierarchy
* cinematic layout
* premium spacing
* smooth animations
* immersive sections
* responsive experience

---

# Animation Rules

Use:

* smooth scroll animation
* stagger reveals
* layered motion
* cinematic transitions
* floating visual effects

Avoid:

* chaotic movement
* excessive animation
* performance-heavy effects

Animations must remain smooth on mobile devices.

---

# Layout Rules

Use:

* large typography
* layered visuals
* asymmetrical composition
* immersive sections
* modern spacing

Avoid:

* boring template layouts
* dashboard UI
* excessive cards
* generic sections

---

# Performance Priority

The website must:

* compile successfully
* deploy successfully on Vercel
* avoid hydration errors
* avoid TypeScript errors
* avoid unstable dependencies

Always prioritize stability and deployability.

---

# Mobile Experience

The mobile version is extremely important.

Requirements:

* responsive layout
* touch-friendly spacing
* optimized motion
* smooth scrolling
* stable rendering

The mobile experience should feel premium and immersive.

---

# CTA Priority

Main CTA:

* Order via WhatsApp

Secondary CTA:

* Open Franchise

WhatsApp CTA should appear multiple times throughout the website.

---

# Coding Rules

Requirements:

* clean architecture
* reusable components
* maintainable structure
* modular sections
* semantic HTML
* TypeScript interfaces

Avoid:

* unnecessary complexity
* excessive dependencies
* messy component structure
* duplicated logic

---

# Final Goal

Create a visually impressive cinematic coffee landing page that feels:

* premium
* artistic
* modern
* emotional
* immersive

The website should look comparable to modern fashion campaign websites and premium coffee branding experiences.
