# Jalani Kopi

A modern, responsive coffee shop landing page created as a portfolio project for Jalani Coffee. The website showcases eight drinks, brand information, franchise details, and direct WhatsApp ordering.

## Features

- Responsive layouts for mobile, tablet, and desktop
- Eight coffee and non-coffee menu items
- Optimized product imagery with `next/image`
- Direct WhatsApp ordering and franchise contact
- Instagram and Google Maps integrations
- Smooth scrolling and lightweight motion effects
- Custom SVG favicon

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Lenis
- Lucide React

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Checks

```bash
npm run typecheck
npm run lint
npm run build
```

## Deployment

The project is ready for zero-configuration deployment on Vercel.
